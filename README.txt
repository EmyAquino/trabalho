Como rodar:
  pip install flask
  python app.py        (abre em http://127.0.0.1:5000)

Coloque as imagens do Figma em static/img/ com estes nomes:
  logo-pense.png   (logo do cabeçalho)
  logo-submite.png (logo grande da página inicial)
  avatar.png       (imagem redonda dos cards)
  card.png         (imagem de destaque dos cards)
